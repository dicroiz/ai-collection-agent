# AI Collection Agent — Project Instructions

## Overview
AI-powered debt collection agent for the Brazilian market. Operator-facing dashboard (English UI) that manages debtors, sends WhatsApp messages, and triggers outbound AI voice calls. All debtor-facing content is in Brazilian Portuguese (pt-BR).

## Architecture
- **Voice calls**: Vapi.ai (orchestrates ElevenLabs PT-BR TTS + Deepgram STT + GPT-4o)
- **WhatsApp**: Meta Cloud API (direct, no BSP)
- **LLM**: GPT-4o via Abacus AI route-llm for negotiation agent (persona: "Ana")
- **DB**: PostgreSQL with Prisma ORM
- **Volume target**: ~4,000 debtors/month

## Theme
- Dark navy/slate background
- Accent: Electric blue (#3B82F6 / hsl 217 91% 60%)
- Status badges: grey=New, blue=Contacted, yellow=In Negotiation, green=Resolved
- Force dark theme (no light mode toggle)

## Key Design Decisions
- No authentication for MVP (internal demo tool)
- Demo/mock mode when external API keys not set (shows yellow warning banner)
- ENV vars set to "not_configured" as placeholder; `isSet()` helper treats this as unconfigured
- Conversation history stored as JSONB in `conversations` table
- All API routes use `export const dynamic = "force-dynamic"`

## External API Keys Required
- META_WHATSAPP_PHONE_NUMBER_ID, META_WHATSAPP_ACCESS_TOKEN, META_WHATSAPP_VERIFY_TOKEN
- VAPI_API_KEY, VAPI_ASSISTANT_ID
- ABACUSAI_API_KEY (auto-configured)

## Pages
- `/` — Operator Dashboard (add debtor form + debtor table with WhatsApp/Call actions)
- `/interactions` — Interaction log with filters, auto-refresh 30s
